# CodeAlpha_RandomQuoteGenerator

## 📚 Description
A simple web app that generates random quotes. Click the "New Quote" button to fetch a new quote, or share your favorite quotes on Twitter using the "Share Quote" button.

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
- Quotable API (https://quotable.io) for random quotes

## 🚀 Features
- Fetches a new random quote with a button click
- Shares the quote on Twitter
- Responsive design for mobile and desktop

## 💻 How to Use
1. Clone the repository
2. Open `index.html` in your browser
3. Click "New Quote" to generate a random quote
4. Share your favorite quotes on Twitter
